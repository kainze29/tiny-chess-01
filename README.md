A chess engine in 4 KB of Python: 0x88 board, negamax with PVS, LMR and null-move pruning, a transposition table, quiescence search, PeSTO piece-square tables, and a fixed 80,000-node budget per move. Built for the make.fun tiny-chess-01 bounty.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:PORT python3 main.py
```
